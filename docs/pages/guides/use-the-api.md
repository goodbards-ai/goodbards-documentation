# Use the GoodBards API

<span class="gb-soon">Guide coming soon</span>

Connect your own tools to GoodBards: push contacts from your website or CRM, and
pull content and results into your reports.

## The stages

1. **Get access**: who in your company can create an API key, and what it may
   do.
2. **Authenticate** your requests.
3. **Common jobs**: add or update contacts, read a campaign's results, generate
   content in your brand voice.
4. **Limits and errors**: rate limits, and what each error means.
5. **Reference**: the public endpoints, with examples.
