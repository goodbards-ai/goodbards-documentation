# Event Management

Run an event end to end — registration, check-in on the day, and follow-up
afterwards.

## What it's for

Events usually mean juggling a registration page, a spreadsheet of attendees and
a clipboard at the door. Event Management keeps all three in one place, and
because registrations become contacts, following up afterwards does not mean
re-typing a list.

## Before you start

- A [form](forms.md) for registration, if you want people to sign up. Use the
  **Registration & sign-ups** category.

## How to set up an event

1. In the sidebar, choose **Marketing → Event Management**.
2. Choose **+ New Event**.
3. Fill in the details — name, type, date, time and venue.
4. Save it as a **Draft** while you prepare, then **Publish** when registration
   should open.

![The Event Management screen, showing events as cards with their status, date, time, venue and registration count](../../img/screenshots/event-management.png)

## Event status

The filters across the top let you see events at each stage. The count beside
each one tells you how many are there.

| Status | What it means |
| --- | --- |
| **Draft** | Being prepared. Not visible to attendees. |
| **Published** | Live, and accepting registrations. |
| **Ended** | The event has taken place. |
| **Cancelled** | Called off. |

## Checking people in

On the day, use **Scan Attendee** to check people in. Each registrant has a QR
code; scanning it records their attendance as they arrive, so you can see who
turned up without a paper list.

## Reading the event cards

Each card shows the event type (for example **Meetup**), the date and time, the
venue, and how many people have registered. Where you have set a capacity, it
shows as `0 registered / 20` so you can see how much room is left.

!!! tip "Venue shows as TBD"
    An event with no venue set displays **TBD**. Fill it in before publishing —
    it is one of the first things registrants look for.

## Good to know

- **Publish before you share the link.** A draft event will not accept
  registrations.
- **Registration numbers are live.** The count on the card updates as people sign
  up; you do not need to refresh a separate report.
- **Follow up while it is fresh.** Attendees are contacts, so you can email
  everyone who came — or everyone who registered and did not — straight after the
  event.
